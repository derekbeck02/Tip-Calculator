# GUI Tip Calcualtor

A desktop tip calculator built with Python, Tkinter, and ttkbootstrap. Calculates common tip percentages and allows users to enter a custom tip percentage.

## Features

- Calculate 15%, 18&, and 20% tip amounts
- Enter custom tip percentage
- Simple GUI built with Tkinter
- GUI styling using ttkbootstrap

## Technologies

- Python
- Tkinter
- ttkbootstrap

## Installation

1. Clone the repository:

```bash
git clone https://github.com/derekbeck02/Tip-Calculator.git
```

2. Install dependencies

```bash
pip install ttkbootstrap
```

## Running the application

```bash
python main.py
```

> Note: On Windows, you may need to use `py main.py` instead.
